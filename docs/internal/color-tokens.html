arXiv Color Tokens

CSS custom properties defined in design-system-staff.css. Add to your shared :root block. All contrast ratios are measured against #ffffff (white) unless noted. Background colours marked "Warm Wash" use #f9f7f7 as the reference surface.

All Tokens

Grouped by semantic role. Do not use tokens outside their intended role — e.g. do not reuse --ds-danger as a general red highlight. Scope: color tokens for UI chrome only. The same :root block also defines the alert-family tokens (--ds-success-*/--ds-info-*/--ds-warning-*/--ds-error-*, documented in alert-styles) and the spacing scale (--ds-space-1…--ds-space-12, documented in spacing) — they exist even though they are not listed here.

--ds-focus-ring #1565c0 / #64b5f6
Universal :focus-visible ring — all interactive elements (buttons, links, inputs). Light mode: #1565c0 Link Blue Light Mode, 5.74:1 on white ✓. Dark mode override: #64b5f6 Link Blue Dark Mode, 7.84:1 on Repository Brown ✓ AAA. (#1565c0 only achieves ~2.6:1 on dark bg — fails 3:1 non-text contrast.)
--ds-border-strong #8b8680
UI boundary grey — for interactive borders, toggle tracks, sort arrows, and control outlines needing WCAG 3:1. 3.61:1 on white, 3.38:1 on Warm Wash, 3.12:1 on table header bg — AA ✓ UI component.
--ds-border-strong #8b8680
Icon button rest outline — aliased to --ds-border-strong. Signals click affordance while passing 3:1 on white. Darkens to --ds-text-disabled on hover/active/pressed.

Disabled state contrast exemption: WCAG 1.4.3 explicitly exempts disabled UI components from contrast requirements. The washed-out colours used in disabled states are intentional — they communicate inactivity while remaining visually connected to their active counterparts.

Underline requirement

Inline links must carry underlines in both modes. In light mode, link vs. body text contrast is 3.02:1 — technically at the WCAG 1.4.1 limit, but too marginal to rely on. In dark mode it is 1.61:1 — underlines are mandatory. Standalone links (no surrounding body text) may omit the underline.

Brand Link Blue #1e8bc3 retired from body-text use. It achieves 3.6–3.8:1 on light backgrounds (fails AA normal text) and 4.1:1 on the dark card surface (also fails). The --ds-link token uses #1565c0 for light mode and #64b5f6 as the dark mode override — a deliberate, documented divergence for accessibility compliance.
