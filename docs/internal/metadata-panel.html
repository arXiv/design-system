Metadata panel

A grid of label + value pairs describing one record — one paper, one user. Use it for the identity block at the top of a record page. Not a card (those hold peers in a set) and not a table (those hold many records).

.ds-meta-panel
The panel, on a <dl>. An auto-fit grid with a 190px minimum column and a 10px radius. Always used with --editable or --reference, never alone.
.ds-meta-panel--editable
The workbench tint: a --ds-accent-wash wash and a lime-family hairline border. Promises that the record can be edited here.
.ds-meta-cell
One label + value pair: a <div> wrapping a <dt> and a <dd>. Padding --ds-space-3 --ds-space-4, gap --ds-space-1. The <dt> takes the condensed label style and --ds-text-muted; the <dd> takes --ds-text.

.ds-meta-panel--reference
The read-only tint: a --ds-surface-active wash and a 4px --ds-accent top bar. Holds system facts only; never put an editable field inside it, because it is styled to read as fixed.

Accessibility essentials

  • Keep the <dl> real. The panel is a <dl>, so a screen reader announces each label with its value. Every <dd> has its own <dt>; a value with no label is a number nobody can place. The <div> cell wrappers are valid HTML inside a <dl>.
  • Label the panel as a region. Wrap the panel in a <section> whose aria-labelledby points at the record's heading, so a screen reader user can jump to it and knows which record it describes.
  • Values are text, not images. A value has to be readable, searchable, and copyable: a rendered badge or a screenshot of a value is none of those.
  • Name every edit control after its field. An edit affordance inside a cell needs an accessible name that says which field it edits, such as “Edit email”, not a bare pencil.
  • Tint is never the only signal. The editable panel contains visible edit controls; the reference panel contains none. Never put an editable field in the reference variant.
  • Contrast is built in. The label colour (--ds-text-muted) clears AA on both washes, and values use --ds-text. Do not restyle either.

Modifiers

High-density modifier

Cells separate with spacing by default. At five-plus columns of mixed-width values, --ruled adds faint cell rules — always fainter than table dividers.

Note

The final cell stretches to the end of its row, so the grid never strands one orphaned cell on the last line.

.ds-meta-panel--ruled
Faint rules between cells, for five-plus columns of mixed-width values. Added to --editable or --reference, never on its own; the rule colour follows the variant and is component-internal.
.ds-meta-cell--span
A full-width cell (grid-column: 1 / -1) for author lists and other long values.

Rules

Tint is a signal, never decoration

Lime wash promises editing lives here; grey wash promises read-only. If neither promise fits the content, do not tint it.

One record only

Rows of similar records belong in a table; browsable peers belong in cards. The panel describes the single subject of the page.

Spacing before rules

Reach for --ruled only when five-plus columns of mixed-width values genuinely blur together — and never expect it to make the panel read as a table; that distinction is load-bearing.
