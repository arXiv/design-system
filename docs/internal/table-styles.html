Table Styles

Base data table, sortable column headers, and filter toolbar patterns used across the admin console and arXiv Check.

Base Data Table

The .ds-table class provides warm-tinted header row, subtle row dividers, and hover highlighting. Condensed uppercase headers use IBM Plex Sans Condensed.

Usage: Apply .ds-table to the <table> element. Add table-layout: fixed inline when fixed column widths are needed. Use .ds-table-footer on a <div> below the table for row counts or pagination.

Sortable Column Headers

Add .sortable to a <th> to make it clickable. Place a <span class="sort-arrow"> inside for the direction indicator. Apply .sort-asc or .sort-desc to the <th> to indicate current sort state.

Sort indicator states:
  • Unsorted — arrow shows ⇕ in muted #b0aba6
  • Ascending — .sort-asc on <th>, arrow shows ↑ in #1c1a17
  • Descending — .sort-desc on <th>, arrow shows ↓ in #1c1a17
Interaction: Clicking a sortable header toggles through: descending → ascending → descending. Clicking a different column resets the previous column to unsorted. Sort logic is application-specific; the CSS only handles visual states.

Filter Toolbar

The .ds-filter component provides a minimal underline-only <select> for filtering data. Typically placed in a toolbar row above or alongside a table. The custom chevron replaces the native dropdown arrow for visual consistency.

Usage: Wrap a <label> and <select> in <div class="ds-filter">. The select gets an underline-only border, custom chevron via background-image, and a focus ring matching var(--focus-ring). Place the filter in a flex toolbar above or alongside the table.
Accessibility: Always associate the <label> with the <select> via for/id. Add aria-label on the select if the visible label text alone is ambiguous.
