Live token values

Read at runtime from design-system.css via getComputedStyle — these reflect the currently active mode and can't drift from the stylesheet. Contrast is text-on-background, computed in the browser (target 4.5:1 AA).

StateBackgroundBorderText / iconContrast

Why this can't go stale. Nothing here hardcodes a hex value — the swatches, the codes, and the contrast ratios are all derived from the live tokens. Change a token in design-system.css and this table updates on the next reload. If the stylesheet ever fails to load, the page visibly breaks, so it doubles as a smoke test.

Usage

Variants: ds-alert-success, ds-alert-info, ds-alert-warning, ds-alert-error. Use role="status" for success/info (polite) and role="alert" for warning/error (assertive); icons carry aria-hidden="true".

<div class="ds-alert ds-alert-warning" role="alert">
  <svg class="ds-alert-icon" viewBox="0 0 24 24" stroke-width="2"
       stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><!-- icon --></svg>
