Metadata Panel

A grid of label + value pairs describing one record — one paper, one user. Use it for the identity block at the top of a record page. Not a card (those hold peers in a set) and not a table (those hold many records).

Editable variant — the workbench

Lime wash signals "act here": edit affordances, links, and chips for the record live inside it.

High-density modifier

Cells separate with spacing by default. At five-plus columns of mixed-width values, --ruled adds faint cell rules — always fainter than table dividers. The final cell stretches to the end of its row, so the grid never strands one orphaned cell on the last line.

Rules

Tint is a signal, never decoration

Lime wash promises editing lives here; grey wash promises read-only. If neither promise fits the content, don't tint it.

One record only. Rows of similar records belong in a table; browsable peers belong in cards. The panel describes the single subject of the page.
Spacing before rules. Reach for --ruled only when five-plus columns of mixed-width values genuinely blur together — and never expect it to make the panel read as a table; that distinction is load-bearing.

Accessibility notes

  • The panel is a real <dl>: screen readers announce each label with its value. The <div> cell wrappers are valid HTML inside a dl.
  • Label color (--grey) clears AA on both washes; values use --text.
  • Edit affordances inside cells need accessible names naming the field ("Edit email"), not a bare pencil.
  • The tints are never the only signal — the editable panel contains visible edit controls; the reference panel contains none.
