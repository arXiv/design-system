Confirm an action that changes nothing on screen

Copy, Permalink and similar actions do their work out of sight: nothing on the page changes. Say what happened, in words for a screen reader and with a visible sign for everyone, and leave focus where it was.

Contents
  1. Where it is used
  2. Copying
  3. Copy, Permalink and similar actions

Where it is used

  • The copy button on every code block, including each citation format in a paper's Cite. See Typography.
  • Copy and Permalink on an equation, a figure or a reference, and Permalink on a section heading. See Buttons and Papers.
  • The theme control, which says which theme is now in use. See Dark mode.

Copying

The copy button on a code block, the one most pages use. Press it: the icon becomes a tick, and a screen reader hears “Copied to clipboard”.

Note

Meets accessibility guideline WCAG 2.2 SC 4.1.3 Status Messages (Level AA)

Relevant code 
<pre><code>@article{palomares2026gauge, …}</code></pre>
<script src="copy-code.js" defer></script>
copy-code.js
Once per page. It adds the copy button to every <pre><code>. After a copy the icon becomes a tick, and a visually hidden role="status" region beside the button says “Copied to clipboard”; both clear after two seconds. If the copy fails, the region says “Copy failed — select the code and copy it manually”.
[role="status"]
Written by the script, never by hand. A status region is announced without moving focus.

Rules

Copy, Permalink and similar actions

  • Say what happened, in words. A visually hidden role="status" region says it: “Copied to clipboard”. Where a page has many controls that do the same thing, it names what was copied: “Link to equation 2.14 copied”.
  • Focus stays on the control.
  • The control keeps its name. The name says what it does: Copy is still Copy after copying.
  • Show it too, where nothing else on the page changes. A visible sign goes with the words, such as a green tick, and both reset after two seconds.
  • Say when it fails, and what to do instead: “Copy failed — select the code and copy it manually”.
