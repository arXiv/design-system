Site header unit

The universal arXiv public-page header: announcement band + black bar (.ds-announcement / .ds-site-header), plus the .ds-skip-link utility. Design approved 2026-06-11 against the spinout-header-footer Cloud Run deployment — which covers ONLY these two pieces; nothing below the black bar is approved chrome. (A breadcrumb band was briefly part of this pattern and removed 2026-06-11: too shallow to justify the real estate, and its links exist elsewhere on the page.)

Live component

Rendered directly from design-system.css. Resize the window: at ≤599px the nav collapses behind the hamburger (the approved mobile treatment); without JS it wraps to a second row instead — every item stays visible, passing WCAG 1.4.10 reflow at 320px and keeping voice-control working. The header is static — it scrolls away with the page (sticky chrome is reader-only; DESIGN-POLICIES.md, decided 2026-06-11).

Behavior contract

  • The skip link (.ds-skip-link) is the first focusable element on the page, visible only on keyboard focus.
  • Logo alt text and aria-labels say "archive" — the spoken form of "arXiv" (Dan Miner: screen readers otherwise produce "ar-zhiv" / Roman-numeral gibberish).
  • The Search control is an <a href="/search"> that JS may upgrade to open a search overlay. Never a dead button — without JS it navigates to the search page.
  • At ≤599px the nav collapses behind a hamburger only after JS enables it: the header script adds .is-collapsible to .ds-site-header and wires the toggle (.is-open on the nav, aria-expanded in sync) in the same call, so the hamburger appears only when it actually works. The default — including no JS — is the wrap (all items visible, WCAG 1.4.10 reflow).
  • Focus rings on the dark bar use --arxiv-focus-ring-dark (#64b5f6); the standard Link Blue ring is invisible against #1c1a17.
  • The announcement is temporal: render only while active, persist dismissal in production, and never attach page-critical function to it.
  • Nothing in this unit is sticky — the whole header scrolls away with the page (decided 2026-06-11; sticky chrome is exceptional at arXiv and reader-only). No scroll-padding duty applies.
  • Type sizes are rem so browser font-size overrides propagate; both bands are hidden in print.
