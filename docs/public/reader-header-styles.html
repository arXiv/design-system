Reader header

The HTML-reader variant of the site header (.ds-reader-header + .ds-toc-trigger / .ds-toc-dropdown / .ds-reading-progress). Light Card Grey — the reader is a content-first surface, so the chrome recedes. Design approved 2026-06-11; reference implementation mockups/public/html-phase1.html. The conventions this pattern embodies are written up for universality review in ../../planning/PROPOSED-GUIDELINES.md.

States

Rest state (52px, full wordmark, labeled nav) and compact state (36px — JS adds .compact once the reader scrolls past the abstract; the same condensed grammar is reused at ≤700px viewports rather than introducing a hamburger). The blue line at the bottom edge is the reading-progress bar, shown mid-document here.

TOC dropdown

Click the trigger to open. The dropdown hangs from the header's bottom edge (no top border or radius) and shares the tint family with the popover panels — all arXiv-layer surfaces read as related. The current section carries the Link Blue left accent. At ≤700px it becomes a full-screen overlay with a prominent close button and 44px touch targets.

Behavior contract

  • Scroll offset: any page using this header sets html { scroll-padding-top: 80px } — closes the 12-filing anchor-under-header bug class (PROPOSED-GUIDELINES.md G1).
  • Compact trigger: JS adds .compact after the reader scrolls past the abstract; removed at top. Never toggled on scroll direction alone.
  • Trigger label shows the current section (IntersectionObserver) — passive orientation, no aria-live (G9). At rest: "Contents".
  • Dropdown closes on outside-click, Esc (focus returns to trigger), and item activation. Current item scrolled into view on open.
  • No-JS: trigger and progress bar hidden; the document's native TOC stays available to AT. Enhancement never carries content (G8).
  • Reading progress is position chrome, never an engagement metric. aria-valuenow updates on scroll; transitions disabled under prefers-reduced-motion (G7).
  • Reading-time estimates must exclude math, figures, and the bibliography from word counts.
