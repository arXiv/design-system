# Canonical asset files

Official arXiv marks and imagery consumed by docs pages, mockups, and (by URL)
other repos — the visual counterpart of the stylesheets and `docs/fonts/`.

Conventions:
- Subfolder per family: `logos/`, `icons/`, `illustrations/` — created as needed.
- SVG is the source of truth; PNG exports carry a size suffix (`arxiv-logo-32.png`).
- kebab-case names; a license/usage note accompanies each family.
- Paths are stable once published — other repos will link them; don't rename casually.
