Spacing

One 4px-based / 8-point scale, and one rule about how to use it. Every gap on every arXiv surface comes from these seven steps — no off-scale values (14, 26, …). Written spec: DESIGN-POLICIES.md (Spacing); tokens: --space-1…--space-12 in internal/design-system.css.

The scale

Seven steps, each roughly 1.5× the last. The gaps in the bars below are the token values — the page pulls them live from --space-*. Production code namespaces them (--arxiv-space-4 in a React/MUI app); the values map 1:1.

--space-14px
Tightest — label→value, icon→text.
--space-28px
Closely related inline items.
--space-312px
Related stacked elements.
--space-416px
Default gap between elements in a section.
--space-624px
Sub-section separation / card padding.
--space-832px
Larger internal padding.
--space-1248px
Breathing space between major sections.

The proximity rule

The gap between sections should be clearly larger than the gap within one — aim for ~3× (e.g., 16px within, 48px between). This is what makes grouping read without borders or boxes. Same content, same words, both cards below — only the spacing differs.

Rules that travel with the scale

Stay on the scale

Reach for a token, never a hand-picked pixel. If a layout seems to want 14px or 26px, it wants an existing step (12 or 24) — or the design is fighting the grid. New values are a change to DESIGN-POLICIES, not a local override.

Between ≈ 3× within

Grouping is carried by contrast in spacing, not by lines. --space-4 within, --space-12 between is the workhorse pair. When a border feels necessary to separate two blocks, first try widening the gap.

Layout is px; type is rem

These spacing tokens set layout distances in px so structure stays stable. Font sizes stay in rem so a reader's browser zoom still governs text (see typography.md). Don't scale gaps with the user's font preference.

Namespaced in production

The canonical names are unprefixed (--space-6). Each codebase adds its own prefix to avoid collisions (--arxiv-space-6 in React/MUI, $arxiv-space-6 in Sass), mapping 1:1 to the values here.
