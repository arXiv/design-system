# Examples

Whole pages built only from documented components. Each example lists the patterns and components it is built from, and names the rule behind each arrangement choice, so a builder takes the reasons rather than copying the layout.

- An example uses no class, token or markup that the docs do not document. Anything new goes into the docs first.
- Read the pattern and component pages first. An example shows how they fit together on one page.
- An example is never the answer to an agent test. A test that builds a page leaves that page's example out of the builder's copy of the repository.
