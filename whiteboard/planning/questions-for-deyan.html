Questions for Deyan

2026-10-05. Questions about the HTML papers renderer that came up while moving decisions from the HTML paper mockup into the design system. Each one is something only the renderer can answer or produce. The design-system rule that depends on it is named under each question.

TeX and math

  1. Is the TeX in each equation's annotation exactly what the author typed? The sample paper shows \displaystyle in aligned cells and braces such as R^{2}. If LaTeXML adds these, can it keep the author's original string, so that Copy in the TeX view gives it back unchanged?
    Depends on it: “The TeX is exactly what the author wrote. arXiv does not strip or tidy it.”
  2. Can headings in LaTeXML's contents list have a plain-text form? A section title that contains math includes the TeX annotation in its textContent, so a contents list built from it shows “Ψ\Psi”. Can LaTeXML output a plain-text form of each heading, or should arXiv's scripts skip annotation elements? (toc.js and anchors.js both read textContent today.)
    Depends on it: “Math in a heading appears as it renders, never as its TeX.”
  3. Are display equations laid out in layout tables? They use <table class="ltx_equationgroup">. Making a wide equation scroll changes it to display: block, which removes the table semantics. Does a screen reader use those rows, or can they take role="presentation"?
    Depends on it: “A wide equation scrolls inside its own box, never the page.”

Stable ids

  1. Are paragraph ids such as S2.p3 the same across LaTeXML upgrades for the same paper version? If not, a paragraph permalink cannot promise to last.
  2. Does every figure, display equation and bibliography entry get a stable id that a Permalink can use?
  3. Can each citation have a stable id, so that a reference can link back to every place it is cited (“Cited by”)?

Markup only the renderer can produce

  1. The <main> landmark round the paper.
  2. A visually hidden “Abstract” heading, so a screen reader user can jump to the abstract by heading.
  3. Footnotes. What does LaTeXML output for a footnote: an inline .ltx_note, or a marker with the note elsewhere? Where is the note that the marker should link to? The mockup's footnote markup was made by hand.
  4. Authors. The mockup's author markup was also made by hand. What does LaTeXML output for authors and their affiliations?
  5. Table scroll regions. Can LaTeXML wrap every tabular, including one with no .ltx_table wrapper today, in an element that can be the scroll region, with role="region", tabindex="0" and a name taken from its caption? Or should arXiv's script add those attributes?
  6. Captions as written. Does the caption text, with its label and punctuation (“Figure 1:”), pass through exactly as the author wrote it?
  7. The bibliography as a direct child of the page container. Can the bibliography, and anything after it, be output there? Only then can arXiv's full-width closing band replace the viewport-width trick the mockup uses.

Stylesheets

  1. Cascade layers. Does the production papers stylesheet import ar5iv and the theme file into named cascade layers, as the mockup's copy does? If not, can it, so that arXiv's rules win without !important?
  2. The bibliography overflow. The bibliography scrolls sideways because of a 10px indent on each entry and a stray 8px. Can this be fixed in the papers stylesheet, for example by moving the indent onto the number cell?
  3. ar5iv's theme control. Will it still appear on the paper page? If it does, can it read and write the same data-theme attribute and storage key as arXiv's theme.js, so the page does not have two theme switches?

References

  1. Can a citation always find its bibliography entry? The citation popover copies the entry whole. When the entry cannot be found, the citation stays a plain link to the reference list with no popover. How often does that happen?

Waiting on a design decision first

  • Missing alt text. If Shamsi decides a paper shows a notice when a figure has no alt text, can the renderer say reliably which figures have none? If she decides it shows nothing, this question goes away.
