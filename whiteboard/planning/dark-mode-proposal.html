Dark mode tints: proposal

2026-10-05. New dark values for the fills that collapse or change strength in the audit. Each value is chosen so it stands out from what it sits on by the same amount as its light-mode value does. Nothing here is in the design system yet.

The idea

In light mode a card is the same white as the page, and a border separates them. Today dark mode raises cards to a lighter brown instead, and that is why a grey fill inside a card disappears: the raised card already uses the grey. The proposal makes dark mode work like light mode. A card is the page colour with a border, and every fill is one value, the same distance from the page in both modes. Every fill is still a warm grey or the accent blue, and no new colour is added to light mode.

FillLightDark nowDark proposed
--ds-surface on --ds-canvas#ffffff 1.00#2b2723 1.17#1c1a17 1.00
--ds-tint-warm on --ds-canvas#f0f0ee 1.14#221f1b 1.06#282622 1.15
--ds-surface-muted on --ds-surface#f0f0ee 1.14#2b2723 1.00#282622 1.15
--ds-surface-hover on --ds-surface#f8f7f7 1.07#1c1a17 1.17#23201d 1.07
--ds-tint-accent on --ds-canvas#edf7ff 1.09#1e3a5f 1.51#1e2328 1.10
--ds-accent-wash on --ds-canvas#d2eafe 1.24#1e3a5f 1.51#202d3c 1.24
--ds-border on --ds-surface#dad8d6 1.42#3a3530 1.22#383531 1.42

The numbers are how far each fill stands out from what it sits on (1.00 is no difference). Text on every proposed fill stays above 6:1 for muted text and above 12:1 for body text.

Internal tools

Internal tools use Access Lime for the same jobs. In light mode the lime wash is one value for both the tint and the wash, with two deeper steps for hover and pressed. The proposed dark values keep those steps at the light-mode distances.

FillLightDark nowDark proposed
--ds-accent-wash on --ds-canvas#f0f9e8 1.08#1a2306 1.06#222217 1.08
--ds-accent-wash-hover on --ds-canvas#e2f3d0 1.17#212e08 1.21#272918 1.17
--ds-accent-wash-active on --ds-canvas#d4edb8 1.26#28380a 1.37#2c3018 1.28
--ds-tint-accent on --ds-canvas#f0f9e8 1.08#28380a 1.37#222217 1.08
