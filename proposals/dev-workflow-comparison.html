2 Claude Code tool

Claude Design imports the system and makes a brand-checked prototype; Claude Code then builds it into your repo as real code (re-run all steps to refresh). The prototype is not canonical — it must be handed off to Claude Code (or another agent, or a person) for production. Faithfulness depends on how accurate we can get our agentic processes. Requires Claude.

3 Package dependency

A fully-specified system shipped as versioned code — a framework-agnostic CSS file (tokens + component classes) any stack can link, with fixed names devs use in their markup. Per-framework builds (React, Jinja, PHP) are optional extra.

4 Hybrid

Invariants (tokens, plain web components) ship as a partial package — any stack, no LLM. Flexible parts go through an agent — Claude Design prototypes them and Claude Code builds them, or any agent reading the repo.
