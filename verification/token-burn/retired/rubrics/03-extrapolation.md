# Rubric — 03 extrapolation (withdrawn-paper notice)

**What this task measures:** whether the rationale prose (BRAND.md, policy "whys", alerts tone guidance, placement rules) lets an agent make good decisions where NO spec exists. This is the key task for the "does the why-context earn its cost" question — compare against the specs-only digest variant later.

There is no single right answer. Grade the *derivation*:

Expected reasoning anchors (the more it genuinely uses, the better):
- Tone: warning-family, not error — alerts guidance says error is for something *failing now*; a withdrawal is advisory state. Respectful to authors (brand: no drama, honest, zero ego; "withdrawal is not misconduct" was in the prompt).
- Placement: main reading column, before the abstract — the placement rule says what every reader must meet goes in the main column (citation-arrival readers must see it). Not rail-only, not a modal, not a toast (z-layer note: arXiv wants ~no toasts).
- Interaction with page: paper stays downloadable (record is permanent — brand + prompt facts); version display relationship acknowledged; title not defaced.
- Uses `.ds-alert` warning construction or a justified variant of it; palette only; author's reason quoted in a quiet way (annotation/serif treatment would be a sophisticated pull).
- Voice: plainspoken copy, no euphemism, no scolding.

Red flags:
- Error-red treatment, alarmist copy, hiding download actions, giant banner defacing the page, invented colors, generic "best practices" reasoning with no reference to this repo's actual guidance.

Designer pass: would you present this treatment in a design review as a credible first proposal? Is the written rationale traceable to real repo guidance (spot-check its citations)?
