Withdrawn Paper Notice

Design rationale for the withdrawn-paper treatment on arxiv.org/abs/… abstract pages. No prior pattern exists for this state; each decision below is traced to the design system documents that settled it.

1. Warning variant, not error — color-mapping.md › Status & alert colors

The notice uses .ds-alert-warning (amber, --arxiv-warning-*), not .ds-alert-error (red). color-mapping.md defines Error/failure for "destructive actions, error states" — system failures and unrecoverable problems. A withdrawal is neither: most withdrawals are honest scientific corrections (an arithmetic error, a flawed assumption) made by responsible authors. Using the error variant would imply misconduct or failure where none exists and would be a false signal to the reader.

Warning is the right register: "proceed with awareness." This choice is grounded directly in a precedent CONTEXT.md already sets: "An older-version notice uses the .ds-alert warning variant." Withdrawal is a more consequential instance of the same semantic — both tell the reader "the state of this paper is not what you might assume."

The notice uses role="alert" (assertive) rather than role="status" (polite), matching the rule in design-system.css: assertive for warning and error states. A screen reader user hears the notice announced immediately without having to navigate to it.

2. Position: after authors, before the abstract — BRAND.md › #1 Interface gets out of the way

The notice appears after the author list and before the abstract. Two constraints pull in opposite directions, and this is the only position that satisfies both.

The title and authors are the paper's permanent scholarly identity. They remain valid and unchanged after withdrawal — a researcher citing this paper cites it by those facts. Placing the notice above them would suggest the paper's very identity is suspect. That is false and unfair to the authors.

Below the abstract, a reader could absorb the paper's claims — possibly invalidated ones — before seeing the warning. A reader arriving from a citation may have no idea the paper was withdrawn. The notice must appear before any content that could be acted on (cited, forwarded, used as evidence).

After authors, before abstract is the only slot. The notice is contextual and in-flow — not a modal, not a sticky overlay. BRAND.md #1 ("The interface gets out of the way") and the Chrome and interaction structure rules in DESIGN-POLICIES.md ("Sticky chrome is exceptional") both support an in-flow, non-sticky treatment.

3. Tone: factual, non-judgmental, transparent — BRAND.md › Voice

BRAND.md Voice: "Honest — we say what's true, including the unflattering parts. Plainspoken — short words, direct sentences."

The notice leads with "Withdrawn" (the bare, unambiguous fact), states the date, shows the author's reason verbatim in italics, and closes with a reassurance about the scholarly record. No legal register, no euphemism ("this paper has been deprecated"), no blame language ("this paper contains errors"). The reason is the most honest thing arXiv can surface — it comes from the author and trusts the reader to interpret it.

The reassurance that all versions remain downloadable directly addresses the anxiety a researcher who has already cited this paper might have: their citation is still valid and the record is still accessible.

4. Persistent, not dismissible — DESIGN-POLICIES.md › Content and interaction

The .ds-alert component supports a dismiss button; the withdrawn notice does not use it. Withdrawal is permanent — there is no future state in which a reader should arrive at the page without knowing the paper has been withdrawn. A dismissible notice could be closed on one visit and forgotten on a return visit, defeating the purpose of the warning.

5. Downloads unchanged — CONTEXT.md › Versions

The paper content stays downloadable. arXiv's explicit policy is that the scholarly record is never deleted. The download buttons appear at their standard weight and styling — no modification needed and no modification appropriate. Because the withdrawn notice is positioned before the abstract, no reader reaches the download buttons without first seeing the withdrawn status. The page's natural flow handles the ordering; no button treatment change is required.

6. WCAG 1.4.1 — color never the sole signal — DESIGN-POLICIES.md › Accessibility

DESIGN-POLICIES.md: "Never use color as the sole means of conveying information. Always provide a secondary cue (text, icon, position change)."

The notice pairs the amber background with a warning-triangle SVG icon (aria-hidden="true", so it does not double-read) and a bold leading keyword "Withdrawn" in .ds-alert-title. In forced-colors mode, the amber hue collapses to a system color but the icon shape and the word "Withdrawn" still carry the meaning. The warning fg #7a5c00 on warning bg #fff8e1 = 5.9:1, clearing AA.

7. Version row: current version labeled WDR — CONTEXT.md › Versions; DESIGN-POLICIES.md › Submission type badges

CONTEXT.md version treatment: "The current version is bold Repository Brown with aria-current, not a link." The withdrawn version inherits this treatment and adds a .type-wdr badge alongside it. DESIGN-POLICIES.md names .type-wdr as "dark" in the submission-type badge palette — Repository Brown background, white text, consistent with how that badge appears in internal tools (arXiv Check submission type column). Prior versions remain available as standard Link Blue underlined links per the established version pattern. No new tokens are needed; all styling comes from design-system.css and palette values already documented in color-mapping.md.

cs › cs.LG › arXiv:2603.14821

Quantum-enhanced optimization of neural network training: A logarithmic speedup

Wei Zhang, Aigerim Bekova, Santiago Pérez

Withdrawn

The authors withdrew this paper on 14 April 2026. Reason: "An error in the complexity analysis in Section 3 invalidates the claimed logarithmic speedup. The correct scaling is quadratic, which does not improve on classical methods."

All versions remain available for download.

Abstract

We present a quantum algorithm for optimizing neural network parameters that achieves a logarithmic speedup over gradient descent on certain loss landscapes. The algorithm exploits quantum interference to escape local minima and leverages amplitude estimation to evaluate the loss function in O(log n) oracle queries. We demonstrate the approach on benchmark image-classification tasks and show empirical convergence rates consistent with the theoretical bound.
