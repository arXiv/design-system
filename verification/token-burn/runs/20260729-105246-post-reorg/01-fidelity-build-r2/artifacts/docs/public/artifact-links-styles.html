Research Artifact Links

The .ds-artifact-links card — a list of a paper's external research artifacts (datasets, code, supplementary material) rendered on the abstract page. Each row is a link that opens off-site in a new tab; the condensed-caps destination badge and the arrow icon signal this visually, and a screen-reader-only "(opens in new tab)" span carries the intent to AT.

Live from design-system.css. Locked to light mode (data-theme="light") — dark-aware tokens not yet extended to this component.

The card at its two natural sizes: a single artifact, and a comfortable multi-artifact list. Hover a row to see the Active Wash treatment; tab into the card to exercise the keyboard-focus ring.

Overflow — 6+ artifacts

When a paper ships 6 or more artifacts, add .ds-artifact-list--scroll to the <ul> and supply tabindex="0" plus an aria-label carrying the total count. The list height is fixed to ~4.5 row heights (180 px) so the bottom row is visibly cut mid-item — the half-item peek from DESIGN-POLICIES.md: a geometric truncation signal that survives forced colors, zoom, and user stylesheets.

Half-item peek

At 180 px, row 4.5 is cut visibly at the bottom of the scroll region. This geometric signal communicates "there is more" without a separate control — it survives forced-colors mode and user zoom levels. The aria-label on the <ul> announces the total count to screen readers.

Design tokens used

All values drawn from the existing palette — no new tokens introduced. Color decisions follow the ready-to-use pairings in color-mapping.md.

TokenValueUsed for
--arxiv-border-light #ddd8d2 Card outer border, row divider hairlines
--arxiv-active-bg #d6e8f7 Row hover background — the shared "arXiv-chrome interactive surface" wash; Library Grey and Link Blue hold AA contrast on this surface
--arxiv-focus-ring / --arxiv-link-blue #1565c0 3px focus ring on :focus-visible
--arxiv-ink #1c1a17 Card title, row label text, row :visited reset
--arxiv-grey #6b6459 Destination badge (5.83:1 on white ✓ AA; also passes on Active Wash)
--arxiv-grey-ui #8b8680 External-link icon at rest (decorative; steps up to --arxiv-grey on hover)
--arxiv-font-sans IBM Plex Sans, … Card shell, row label, title
--arxiv-font-condensed IBM Plex Sans Condensed, … Destination badge — same condensed-caps treatment as .ds-acc-body dt labels

Secondary signal for off-site links. The external-link icon (.ds-artifact-ext-icon) is aria-hidden="true" — it is a visual redundant cue only. The binding signal for AT is the .is-sr-only "(opens in new tab)" text inside each <a>. WCAG 1.4.1: never color or an icon alone.

No visited-purple on rows. The .ds-artifact-row:visited { color: var(--arxiv-ink) } rule suppresses the browser's default visited-link purple. Artifact rows are a structured list, not a bibliography — the visited state would suggest a history-scanning context that doesn't apply here. Researchers who want to track which repositories they've opened can use browser history.

Usage

The card is a self-contained <section> with a heading and a list. Place it in the abstract page's sidebar rail alongside the Versions and Paper information accordions.

Short list (1–5 artifacts — no overflow modifier)

<section class="ds-artifact-links" aria-labelledby="artf-hd">
  <h2 class="ds-artifact-links-title" id="artf-hd">Research artifacts</h2>
  <ul class="ds-artifact-list" role="list">
    <li>
      <a class="ds-artifact-row" href="https://zenodo.org/record/…"
         target="_blank" rel="noopener noreferrer">
        <span class="ds-artifact-label">Training data</span>
        <span class="ds-artifact-dest">Zenodo</span>
        <svg class="ds-artifact-ext-icon" viewBox="0 0 12 12"
             aria-hidden="true" fill="none" stroke="currentColor"
             stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round">
          <path d="M3.5 8.5L9 3M5.5 3H9V6.5"/>
        </svg>
        <span class="is-sr-only">(opens in new tab)</span>
      </a>
    </li>
    <!-- repeat <li> for each artifact -->
  </ul>
</section>

Long list (6+ artifacts — add .ds-artifact-list--scroll)

<ul class="ds-artifact-list ds-artifact-list--scroll"
    tabindex="0" role="list"
    aria-label="12 research artifacts — scroll for more">
  <!-- rows -->
</ul>

Overflow threshold — 5 rows. At 5 or fewer rows the card shows everything; no scroll, no modifier. At 6+ rows add .ds-artifact-list--scroll to the <ul>. The visible height (~4.5 rows at 180 px) is set so the bottom item is cut mid-item — the half-item-peek truncation signal from DESIGN-POLICIES.md. Set tabindex="0" and aria-label="N research artifacts — scroll for more" so the region is keyboard-reachable with an accessible name that carries the total count.

External links must use rel="noopener noreferrer". Every <a> that opens target="_blank" needs both attributes to prevent the opened page from accessing window.opener and to protect referrer information. The .is-sr-only "(opens in new tab)" inside the link text tells screen-reader users the same thing the arrow icon tells sighted users.

Heading level follows the page outline. The example uses <h2> but the right level depends on the surrounding heading hierarchy — never skip levels because the element is inside a card. If the rail's surrounding section is already an <h2>, use <h3> here.
