Read

Version 2 has a better "All sections" page because the main content is higher up on the page. Both versions have too many headings on the All section page. "Subject groups" feels superfluous because there is little content on this page. Also on All sections, the top heading calls them "sections" while the next heading calls them "groups" and that is confusing for users and something that should be called out and clarified.

Both versions look nearly identical for the Activity charts page, except that version 1 added what looks like a breadcrumb above the H1 heading. So I prefer version 2 for this page also. Using a breadcrumb is incorrect. arXiv does not have a breadcrumb element in our DS on purpose because our sitemap is broad but shallow. A better place for that link would be in the navigation area of the header.

Both versions did not add "staff reports" to the header nav. I think that is the most appropriate place for that link, alongside the link to All sections. Just a small link at the bottom of the page is too hard to find, too obscure, for what is in fact one of the sections of this tool.
