## Before you finish: review the layout

Look at each page you built as a reader would, on a laptop screen, and revise it before you finish.

1. **Name the primary content** of each page: the primary thing the reader came for. Write it down in a sentence.
2. **Check that it starts as high as it can.** Everything above it must earn its place.
3. **Evaluate each element or content that displays above it** and ask: "Is this the right place in the content hierarchy for this content? Should this content be in a sidebar, inside an accordion, behind a control, or in a tooltip?"
4. **Check each component against the alternatives.** For each choice, name the other components the docs offer for that job, and keep yours only if it is the better fit (docs/layout-patterns.html, *Evaluating user needs* and *The main content comes first*).
5. **Change the pages** where the review shows a better arrangement, then end with a short list of what you changed and why.
