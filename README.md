# arXiv Design System

arXiv's DNA for product design and frontend development.

A proto-design-system defining design tokens, component specifications, and accessibility requirements for arXiv's frontend. Currently focused on internal tools (arXiv Check and Admin Console), with public-facing patterns (arxiv.org, abstract pages) planned.

## Quick start

Open any `.html` file in `design-patterns/internal/` in a browser — no build step needed.

## Structure

- **`design-patterns/internal/`** — Active. Component CSS, design tokens, and interactive pattern references for arXiv Check and Admin Console.
- **`design-patterns/public/`** — Planned. Patterns for arxiv.org and researcher-facing pages.
- **`visual-audit/`** — Platform-wide visual audit documenting arXiv's current 11 distinct visual languages.
- **`CONTEXT.md`** — Full project overview and directory guide.
- **`DESIGN-POLICIES.md`** — Hard constraints: accessibility, token usage, component conventions.
