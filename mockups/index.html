Mockups

Work-in-progress page explorations, organized by context. Everything here iterates freely and is never a build or style reference — patterns are promoted into the documentation when they stabilize.

Public — arxiv.org pages

  • Abstract page — Phase 2

    The paper landing page: title, authors, abstract, format actions, citation export, Labs toggles.

  • HTML paper — Phase 1

    The abstract page and the full-paper reader on one continuous surface, at Phase 1 scope: reader header with TOC dropdown, citation popovers, margin notes, element pills.

  • Labs opt-in modal

    The opt-in dialog for Labs features, layered on a saved arxiv.org page.

Internal — staff tools

  • Admin Console — user page

    User record: metadata panels (editable + reference), permissions toggles, owned papers, activity. Home of the action-bar and metadata-panel patterns.

  • Admin Console — paper details

    Paper record with the green metadata panel, rendered fields, and accordion panels.

  • Admin Console — ownership requests

    Reviewing a paper-ownership request: per-paper decisions, author matching, request metadata.

  • arXiv Check — checkmark & save

    Header affordances for checkmarking and saving in the moderation tool, plus three annotated design comps in the same folder.

Everyone in these mockups is fictional

All names, emails, papers, and addresses are invented placeholder data. See the mockups README for what's here and how feedback works.
