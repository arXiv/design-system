Smileybones: the arXiv design system

These pages hold arXiv's approved patterns for front-end interfaces built around accessibility, usability, and our brand. They hold design tokens, component specs, typography, color, accessibility requirements, interactive pattern references, and more. Optimized for both human and agent digestion, the aspirational dream is that you give your agent your content, goals, and the link to the DS and say "make it so". To get there, your feedback and implementation experiences are welcome so we can improve it together.

Components

Colors

The full arXiv palette, rendered.

Dark mode

In the design system, every colour comes from a token and the tokens flip in each mode.

Typography

arXiv sets all text in the IBM Plex family with STIX Two Math for notation.

Spacing

Every gap on arXiv pages comes from one spacing scale.

Icons

The design system uses the Lucide icon set which is open source, community supported, and available for both commercial and non-commercial use under the ISC license.

Buttons

Each arXiv button family shares the same mechanical spec, with color used to differentiate by context: Open Blue for public pages and Access Lime for internal tools.
