The three warm greys form a deliberate ladder — one stop per contrast tier (disabled / UI boundary / text). Don't introduce intermediate values without a DESIGN-POLICIES.md change.

Two contexts, two accents — never crossed

Public pages — clean, fast, brown-and-blue

Researcher-facing, content-first, minimal chrome. Color comes from the logo, links, and subtle tinted bands.

  • Primary buttons: Open Blue #a5d6fe
  • Toggles on-state: Link Blue #1565c0
  • Section bands: Warm Wash → Grey Hover → Grey Active

Internal tools — warm, utilitarian, lime-accented

Staff-facing workspaces (arXiv Check, Admin Console). Access Lime signals "you are in a staff tool."

  • Primary buttons: Access Lime #c4d82e
  • Secondary: lime tint #f0f9e8, border #9cb522
  • Toggles on-state: lime green

Do not cross the accents. Access Lime never appears on public pages as an interactive color; Open Blue never on internal tools. The color difference is functional — it tells staff which context they're working in. (DESIGN-POLICIES.md)

Accents — big gestures only

High-energy "pop" colors. Both fail text contrast on white, so they are restricted to fills, thick borders, and graphic elements — never text or small UI.

Status & alerts

One semantic system on public and internal surfaces. Every state also carries an icon and a leading word — never color alone (WCAG 1.4.1). Light-mode values shown; dark overrides live in design-system.css.

StateSampleBackgroundBorderTextContrast
SuccessSuccess: saved#e8f5d8#6b8e1e#4a5a0a6.7:1 ✓
InfoInfo: new version#e7f1fd#5a82c8#1a3a789.6:1 ✓
WarningWarning: viewing v1#fff8e1#e8b800#7a5c005.9:1 ✓
ErrorError: upload failed#fdeaea#c62828#8b00008.6:1 ✓

Success is lime-olive, not forest green — arXiv has no success-green, and introducing one would loosen the palette. Info is navy, deliberately darker than Link Blue so banners are never mistaken for links. The error border is Danger Red #c62828 — the functional color for destructive actions and error states everywhere, deliberately distinct from heritage Campus Red. Component usage and dark-mode variants: alert-styles.html.
