Site header unit

The universal arXiv public-page header: announcement band + black bar + breadcrumb (.ds-announcement / .ds-site-header / .ds-breadcrumb), plus the .ds-skip-link utility. Design approved 2026-06-11 against the spinout-header-footer Cloud Run deployment. Codified as one unit — the approved deployment treats the three pieces together (audits/2026-06-11/AUDIT-EVALUATION.md).

Behavior contract

  • The skip link (.ds-skip-link) is the first focusable element on the page, visible only on keyboard focus.
  • Logo alt text and aria-labels say "archive" — the spoken form of "arXiv" (Dan Miner: screen readers otherwise produce "ar-zhiv" / Roman-numeral gibberish).
  • The Search control is an <a href="/search"> that JS may upgrade to open a search overlay. Never a dead button — without JS it navigates to the search page.
  • Focus rings on the dark bar use --arxiv-focus-ring-dark (#64b5f6); the standard Link Blue ring is invisible against #1c1a17.
  • Breadcrumb separators carry aria-hidden="true"; the current page is a <span aria-current="page">, not a link. The breadcrumb is the page's upward path to the category listing (research item AUXDH-950/951).
  • The announcement is temporal: render only while active, persist dismissal in production, and never attach page-critical function to it.
  • Nothing in this unit is sticky — the whole header scrolls away with the page (decided 2026-06-11; sticky chrome is exceptional at arXiv and reader-only). No scroll-padding duty applies.
  • Type sizes are rem so browser font-size overrides propagate; all three bands are hidden in print.
