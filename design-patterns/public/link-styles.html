Link Styles

The canonical .ds-link utility class for inline text links on public-facing pages. Four interactive states (default, hover, visited, focus) driven by the --arxiv-link-blue / --arxiv-link-hover / --arxiv-link-visited tokens, with dark-mode overrides scoped to @media (prefers-color-scheme: dark). DESIGN-POLICIES.md: inline body links must be underlined; standalone nav links may omit it.

The four states

Default is Link Blue with a 2px-offset underline. Hover deepens the color (no underline thickness change — kept subtle to avoid layout shift). Visited shifts to Visited Purple. Focus shows the 3px Link Blue ring via :focus-visible.

In context

Inline within body text and within muted-grey secondary text. The visited state matters most for inline references in long articles, where it helps a reader scan papers they've already followed up on.

Tokens

Defined in design-system.css. Light values in :root; dark-mode overrides scoped to @media (prefers-color-scheme: dark) with a [data-theme="light"] opt-out.

--arxiv-focus-ring = Link Blue = Link Blue (dark) 3px outline, 2px offset on :focus-visible

Inline body links must be underlined. Color contrast against body text is only 3.0:1 in light mode — too marginal to rely on alone. Underlines are mandatory for inline links per DESIGN-POLICIES.md and WCAG 1.4.1 (use of color). Standalone navigation links (header, footer, button-like surfaces) may omit the underline.

Disabled state. Use --arxiv-grey-dis (#b0aba6) for the disabled color and set pointer-events: none. The underline stays so it's still recognisable as a (currently-unavailable) link. The disabled state falls below AA on contrast — WCAG exempts disabled controls from contrast requirements.

Visited memory. The Visited Purple is intentionally strong, not a faint after-state. Researchers reading long bibliographies and listings benefit from seeing what they've already followed up on; a too-subtle visited treatment defeats the purpose. If a specific surface (e.g., a navigation breadcrumb) needs to suppress visited styling, override :visited { color: inherit } locally.

Usage

Two patterns for applying the styles.

Utility class. Add .ds-link to specific anchors you want to style. Use this when you're cherry-picking — for example, in a page where some links should follow the public-side treatment and others (button-styled, nav-styled) should not.

<a class="ds-link" href="...">link text</a>

Scoped base rule. Apply the same styling to every <a> inside a content surface (article, paragraph block) without per-anchor classes.

.article-body a {
  color: var(--arxiv-link-blue);
  text-decoration: underline;
  text-underline-offset: 2px;
}
.article-body a:hover    { color: var(--arxiv-link-hover); }
.article-body a:visited  { color: var(--arxiv-link-visited); }
.article-body a:focus-visible {
  outline: 3px solid var(--arxiv-focus-ring);
  outline-offset: 2px;
}
