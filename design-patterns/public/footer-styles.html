Behavior contract

  • Real <footer> landmark; the link row is a <nav aria-label="Site navigation">.
  • Dot separators must carry aria-hidden="true" — screen readers otherwise announce “middot” between every link.
  • Funder logos carry organization names as alt text.
  • External links (Operational Status) use target="_blank" + rel="noopener noreferrer" + a screen-reader-only “(opens in new tab)” notice.
  • Type sizes are rem so browser font-size overrides propagate (accessibility-priorities.md).
  • Hidden in print (@media print) — printouts keep the content, not the chrome.
  • Wording is exact-match to the approved deployment; do not paraphrase the acknowledgment line.
