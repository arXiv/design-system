# Public-Facing Design Patterns

Design patterns for arxiv.org, abstract pages, search, and other researcher-facing interfaces.

## Status

Planned. The design system is currently being developed starting with internal tools (see `../internal/`). Public-facing patterns will follow.

## What will be shared

Color tokens, typography foundations, and accessibility requirements defined in `DESIGN-POLICIES.md` apply across both internal and public patterns. The component layer (buttons, tables, form elements) will likely differ to suit the different audience and context.

## Current reference

The brand color palette is documented in `../internal/color-tokens.html`. The visual audit in `/visual-audit/audit-report.md` documents the current state of arXiv's 11 distinct visual languages — the fragmentation that this design system aims to resolve.
